# 开源与独立版本边界说明

## 赛前已公开内容

- GitHub 仓库中的 Multisim MCP 协议服务、通用连接器、测试框架、报告格式和基础验证器。
- 仓库依赖及其各自许可证，详见根目录 `LICENSE` 与 `THIRD_PARTY_NOTICES.md`。
- NI Multisim 软件、其安装授权、数据库和厂商模型不随项目分发。

## 独立产品开发内容

后续独立版本将单独维护自然语言需求编排、多 Agent 任务分解、企业器件库、私有知识库、批量多板优化、权限审计和商业部署模块。尚未公开的实现、数据、提示词、评测集和客户配置不应放入比赛材料或公开仓库。

## 对外表述原则

使用“基于开源 Multisim MCP 的产品原型”描述当前成果；不声称开源仓库本身拥有 NI 软件或第三方模型的所有权。参赛前应获得组委会对既有开源代码、比赛新增材料和后续商业版本权属范围的书面确认。
