# 桥式整流原生插件验收（2026-09-13）

开发版新增 `plan_natural_rectifier` 和 `run_natural_rectifier`，完成有限自然语言需求 → 参数设计 → Multisim 原生图纸 → OP/TRAN → 保存回读 → 图纸、CSV、波形和 HTML 报告。此改动尚未包含在已发布的 `1.3.0rc1` 安装包中。

## 使用

在源码版本启动的 MCP 服务中使用 `experiment` 或 `full` profile。宿主 AI 调用：

```json
{
  "name": "run_natural_rectifier",
  "arguments": {
    "text": "设计12Vrms 50Hz桥式整流，负载100mA，纹波不超过1V",
    "output_dir": "D:/experiments/bridge-001",
    "execute": true
  }
}
```

默认 `execute=false` 仅预览，输出目录必须不存在。实际运行要求 Windows、本机授权 Multisim 14.3，以及从本机样例提取的 AC_VOLTAGE、R/C、1N4001GP 元件和完整关联模型。旧模板包缺少 `d_model.xml` 时，重新运行 `tools/bootstrap_local_component_pack.py`；模型文件不随公开安装包分发。

真实插件验收命令（需设置 `PYTHONPATH=mcp_server` 和 `MULTISIM_MCP_TEMPLATE_DIR`）：

```powershell
python tools/run_rectifier_plugin_acceptance.py --output D:/experiments/bridge-plugin-001
```

该脚本通过真实 MCP stdio 调用，核对返回结果与落盘 `acceptance.json` 一致，并校验 manifest 中每个文件的 SHA-256。

## 范围及验收

- 输入 4–18Vrms、50/60Hz，电阻负载设计电流 5–200mA，纹波上限 0.1–2V；部分组合因电容范围限制会被拒绝。
- 采用明确的本地 **1N4001GP** 模型。1N4007 等其他型号不能换标签代用。
- 默认输入 12Vrms、50Hz、负载 100mA、纹波上限 1V；可明确指定 470–4700μF 的电容。未指定电容时按纹波估算选择有余量的容量。
- 负载电阻由预期输出电压和目标电流计算，写入工程的真实参数；不再固定为 10Ω。验收允许负载电流相对设计目标偏差 ±10%，不声称是恒流负载。
- 正弦源零偏置 OP 应接近 0V，整流输出与纹波使用后六个周期的瞬态窗口验收。均值按不均匀求解器时间点积分；窗口边界插值，缺失、稀疏、乱序及非有限值证据拒绝通过。
- 核对原始差分输入是否匹配声明正弦的幅度、频率、相位与极性；检查相邻稳态窗口的均值差。
- 原生导出的连接表验证全部引脚，保存后核对四个二极管的模型身份和定义摘要，并回读源频率/幅度、电阻和电容参数。缓存标签不能掩盖参数错误。

输出包括 `native/circuit.ms14`、`native/schematic.png`、逐项分析 CSV、`waveform.svg`、`ripple.svg`、`report.html` 和带摘要的 manifest。使用桥式布局、竖直并联滤波电容/负载，隐藏探针面板。图中的交流支路交叉不代表电气相连，连接关系以原生引脚回读为准；新图纸仍需人工图面复核。

## 本机实测

Windows / Multisim 14.3 / 32 位 COM worker；默认案例还通过了含中文目录的真实 MCP 调用。下表来自原生 CSV，电流为输出均值除以核验后的负载电阻。

| 输入和要求 | 输出均值 | 峰峰纹波 | 负载电流 |
| --- | ---: | ---: | ---: |
| 12Vrms / 50Hz / 100mA / ≤1V | 15.012V | 0.547V | 99.18mA |
| 4Vrms / 50Hz / 5mA | 4.268V | 0.084V | 5.20mA |
| 18Vrms / 60Hz / 200mA | 23.281V | 0.666V | 197.48mA |
| 12Vrms / 50Hz / 100mA / ≤0.3V | 15.075V | 0.160V | 98.12mA |

这验证了所列工况，不证明全部连续参数组合或其他 Multisim 版本已认证。模型依赖本地授权包；不是独立模型方程的交叉验证。

## 后续元件接入经验

1. 先确认原生模型身份、关联模型对象和端口名称，再开放规划器；不能先输出无来源型号。
2. 源的参数表随载体变化：AC_VOLTAGE 的幅度、偏置、频率索引不同于 DC/PULSE。原生端口编号也要按实际载体验证，不能统一套用旧顺序。
3. 变换符号时同步变换引脚坐标；滤波电容的旋转方向决定上端是哪个引脚。文本独立反向旋转保持可读。
4. 需求值 → 计算值 → 网表 → 保存后原生参数 → 实测指标必须逐层比较。模板默认值、缓存标签或仿真成功都不能代替这些检查。
5. COM 返回的是自适应求解器时间点，采集步长不等于积分步长。不能直接对样本做算术均值，也不能把零偏置正弦源的 OP 当作稳态整流输出。

尚未包含源阻抗、浪涌、二极管峰值电流/温升、电容 ESR/纹波额定值、元件容差、稳压控制、PCB、隔离安规及实物验证。当前只做参数化低压整流仿真，不应称为可直接制造的工程级电源设计，也不是任意复杂电路自动优化。
