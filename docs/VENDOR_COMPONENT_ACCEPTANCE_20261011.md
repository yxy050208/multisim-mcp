# 真实运放元件准入记录（LM324AJ）

本记录把真实供应商模型的原生证据与理想模型、便携行为模型分开。当前公开代码
只记录准入合同和结果摘要，不分发 NI 模板、模型正文、`.ms14` 工程或本地授权包。

## 精确版本范围

目前只有 `compatibility/components-14.3.json` 提供真实 LM324AJ 的已验证映射：

| 字段 | 已记录值 |
| --- | --- |
| Multisim | 14.3 |
| 逻辑族 | `lm324aj-section-a` |
| 原生名称 | `LM324AJ` |
| A 单元引脚 | `1IN+`, `1IN-`, `VS+`, `VS-`, `1OUT` |
| 模型来源 | 本机授权包中的 `LM158_4` |
| 验证方法 | `native-vendor-sampled` |
| 覆盖分析 | OP、AC、TRAN |

请求 14.2、14.3.1 或其它版本时，解析器必须返回 `unavailable`，不会把 14.3
的模板或引脚顺序复制给邻近版本。新版本需要单独探测 Automation API、提取本机
授权模板、核对引脚和模型对象，并完成保存重开及原生仿真后才能加入清单。

## 原生结果

在 Multisim 14.3 中，模型对象、引脚连接、保存重开后的模型身份和模型正文指纹均
保持一致。未校准方案的工作点输出为约 `1.034418 V`，在 `0.99..1.01 V` 目标下
明确返回 `target-not-met`；通带增益和高频衰减检查仍按同一验收范围记录。

随后根据首次原生测量计算一个有界的零点校准候选，重新生成整个工程并再次运行 OP、
AC、TRAN。校准候选的工作点输出约为 `0.9999987 V`，瞬态稳态窗口约为
`0.9999987..1.0000022 V`，通带增益约为 `9.961..10.000`，原生采样要求通过。

这个校准候选使用理想 `VTRIM` 电压源，只证明“测量→调整→再验收”的工具闭环可用，
不代表已经完成可量产的参考源、调节电路、温漂、容差或硬件校准设计。真实模型结果
也不适用理想线性方程的独立参考比较，报告必须保留
`verification_method=native-vendor-sampled`、`reference_applicable=false`。

## 第二个自然语言需求变体

为确认入口没有绑定到固定的毕业设计数字，另用自然语言请求：`50 mV` 输入、总增益
`5`、截止频率 `500 Hz`、`±12 V` 供电、`47 kΩ` 负载。修正解析器后，工程中的供电
网为 `VCC=12 V`、`VSS=-12 V`，通带窗口自动收窄为 `5..50 Hz`，避免把两级 RC 已经
明显衰减的 `100 Hz` 错当成通带上界。

Multisim 14.3 原生运行生成 5 个反馈/电容候选和 1 个测量反馈校准候选。未校准候选
均保留为 `target-not-met`；校准候选通过保存重开、全引脚、模型身份、OP/AC/TRAN 和
报告清单门禁：

| 指标 | 原生采样结果 |
| --- | --- |
| 工作点输出 | `0.2499983 V` |
| 5–50 Hz 增益 | `4.95083..4.99984` |
| 5–50 kHz 之外的衰减窗口 | `0.000499..0.04951` |
| 阶跃前窗口 | `−18.47 µV` 附近 |
| 稳态窗口 | `0.2499983..0.24999833 V` |

原始失败目录和修正后完整证据分别位于本机忽略目录
`release/vendor-lm324-variant-20261011/` 与
`release/vendor-lm324-variant-20261011-fixed/`。它们只用于开发复核，不是公开模型
或授权模板分发包。

## 接入门槛

新的真实元件必须同时通过：

1. 精确版本清单和完整引脚合同；
2. 生成前的模型/模板/供电检查；
3. Multisim 保存重开后的全引脚 ReportNetlist；
4. 模型身份、关联 `CiModel` 和正文哈希回读；
5. OP 以及适用的 AC/TRAN 原生采样；
6. 输出通道、报告和 `manifest.json` 完整性检查。

任何一项缺失都保持 `unverified` 或失败关闭。`LM324M`、其它厂商运放以及未探测的
Multisim 版本不继承本记录。

复现入口见 [`THESIS_PLUGIN_ACCEPTANCE_20260909.md`](THESIS_PLUGIN_ACCEPTANCE_20260909.md)
和 `tools/run_thesis_plugin_acceptance.py`。完整证据保存在本机忽略目录
`release/vendor-lm324-native-20261011-calibrated/`，不属于公开分发资产。
