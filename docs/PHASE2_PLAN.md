# 第二阶段：分立器件与工程约束

第二阶段先实现可审计的共射放大器子集，再扩展电源和波形整形。每个模板必须经过 CIR
拓扑检查、SPICE 预检、Multisim 原生 OP/AC/TRAN 和最终 `.ms14` 回读四道门禁。

首个子集固定为：单个 NPN、分压偏置、集电极电阻、发射极电阻、输入/输出耦合电容、
单电源，目标为静态工作点和中频电压增益。暂不宣称覆盖功率级、热稳定、器件容差或任意
晶体管型号。元件适配器必须记录数据库型号、引脚语义和模型指纹，模型缺失时直接失败。

完成顺序：共射 CIR 合同 → 受限自然语言解析 → 候选参数搜索 → 原生仿真验收 → 报告与
版本兼容回归。
