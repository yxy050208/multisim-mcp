# 毕业设计场景：真实模型与瞬态插件验收

2026-09-09 在本机 Multisim 14.3、Python 3.12 32 位环境，通过真正的 MCP stdio 会话调用
`run_generated_analog_project`。本轮测试的是插件；宿主提供结构化方案并按结果调整方案，
没有调用外部大模型来证明任意自然语言规划能力，也没有物理电路板测试。

## 输入要求与固定验收标准

低压传感器信号调理：100 mV 输入、±15 V 供电、100 kΩ 负载、两级 RC 低通，
两个独立 LM324AJ 封装各使用 A 单元。使用本地安装样例中的 LM158_4 厂商宏模型。

所有候选保持相同标准，未通过修改验收范围来制造“优化成功”：

| 指标 | 要求 | 未校准 | 校准后 |
| --- | --- | --- | --- |
| 工作点输出 | 0.99–1.01 V | 1.0344183 V，失败 | 0.99999867 V，通过 |
| 10–100 Hz 电压增益 | 9.9–10.01 | 9.96108–10.00002，通过 | 9.96108–10.00002，通过 |
| 10–100 kHz 电压增益 | ≤0.26 | 最大 0.246713，通过 | 最大 0.246713，通过 |
| 阶跃前 0–0.9 ms 输出 | ±20 mV | 34.3773 mV，失败 | 约 −0.04233 mV，通过 |
| 1 ms 阶跃后，2–5 ms 输出 | 0.99–1.01 V | 约 1.03442 V，失败 | 0.99999867–1.00000222 V，通过 |

校准根据首次实测工作点误差和通带增益计算，在传感器输入路径增加 −3.44182 mV
的独立直流校准源，随后重新生成整个电路并重跑三项实验。这证明一个有界的测量→
改方案→再验收闭环。校准源是仿真原型，实际参考电压、调节电路、温漂与器件容差
仍需设计，不能宣称完整硬件优化或全局最优。


## 本轮发现并处理的接入问题

1. **原生替换不保证连接保留**：OPAMP5 替换为 LM324M 返回成功，但信号引脚从
   `IN+ / IN- / OUT` 变为 `1IN+ / 1IN- / 1OUT` 后断开。另一个载体替换发生隔离
   worker 崩溃。LM324M 未获支持，也未被静默当成 LM324AJ。
2. **模型换行丢失**：解码 XML 的属性包含原始换行，普通 XML 解析会将其变成空格，
   使 SPICE 注释吞掉后续模型行。现在读取前保护属性换行。
3. **编码器不会还原数字换行实体**：写成 `&#10;` 时模型内留下字面量；现在按原生
   编码器格式写回原始换行，并核对保存后的模型指纹。真实换行与字面量实体分别处理。
4. **关联模型对象**：提取和生成保留 LM324AJ 的 CiModel 正文、关联和本地作用域。
5. **漏读数字开头的端子**：连接表解析现在接受 `1IN+` 等名称，缺失或接错仍失败。
6. **模板文件名不是引脚语义**：旧包将正端放在 `v_port1.xml`，新包按实际编号排序。
   现在按 DC_POWER 原生端子名 `2=正、1=负` 绑定，避免正负供电倒接。
7. **全新安装缺探针**：bootstrap 现在同时提取探针元件、符号和仪器状态，支持新包
   直接执行原生观测。
8. **复制源样例残留标签**：新生成的 LM324AJ 使用自身名称与单元标号，不继承样例的额外 U1 文本。

原生拓扑正确不等于图面排版已经完善。当前导出图仍有较多正交交叉和较长的供电线，
探针信息框与标签也需要进一步改善；这不作为出版级原理图排版验收。
# 自然语言模拟前端入口

已增加 plan_natural_analog_frontend 与 run_natural_analog_frontend。它们把中文或英文传感器前端描述转换为同一套 LM324AJ、OP/AC/TRAN 和采样验收契约；解析器会拒绝 ADC、数字、开关电源和多板等超出范围的要求。该入口是可审计的有界规划器，不是任意复杂电路的通用大模型。

执行模式会先在 Multisim 原生模型上顺序运行 5 个 R/C 参数候选，再按实测直流输出选择候选，并在需要时加入零点校准电压重新执行 OP、AC、TRAN。根目录的 `acceptance.json` 在每个候选完成后写入一次，因此长时间运行被中断时仍保留已完成候选；最终文件还记录选中候选、校准量、各候选状态和选中方案的完整产物路径。
