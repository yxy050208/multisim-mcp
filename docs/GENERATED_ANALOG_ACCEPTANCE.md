# 自动生成电路的原生验收

2026-09-08 已在本机 Multisim 14.3 完成以下闭环：生成可编辑 `.ms14` → 原生 COM 仿真 →
比较电阻候选 → 选择方案 → 导出工程、电路图、完整数据与实验报告。
这个基准覆盖理想分压电路和无负载 RC 低通，不代表任意电路生成或整个独立软件已完成。

## 本次实测

- 分压：10 V 输入、两个 1 kΩ 电阻，原生输出约 5 V、电流幅值约 5 mA。
- RC：C1=100 nF，目标截止频率 1 kHz。初值 R1=1 kΩ，另外比较三个 E24 候选。
- 每个 RC 值都执行 OP、AC、TRAN，合计 13 项原生分析。
- AC 为 10 Hz–100 kHz、每十倍频程 40 点，共 161 点；同时读取输入和输出的复数值。
- TRAN 输入为延迟 100 μs、上升沿 1 μs 的 0→1 V 脉冲，仿真至 1 ms；本次每通道返回 70 个求解器时间点。
- 运行前的几何预检通过，已检查 Multisim 导出的电路图；元件引脚与导线对齐。

| R1 | 实测截止频率 | 对 1 kHz 的误差 |
| --- | ---: | ---: |
| 1 kΩ（初始） | 1591.376 Hz | 59.138% |
| 1.5 kΩ | 1060.985 Hz | 6.098% |
| 1.6 kΩ（选中） | 994.577 Hz | 0.542% |
| 1.8 kΩ | 884.016 Hz | 11.598% |

选中方案的最大瞬态误差约 0.433 mV，最大复数增益误差约 1.60e-9。
截止频率来自原生扫频增益在半功率点的对数插值。选择候选使用实测指标；
解析式 `H(jω)=1/(1+jωRC)` 及有限上升沿的阶跃响应用于独立验错。
不能用源 SPICE 文本的仿真结果代替这些原生工程的测量。

## 复现

在项目根目录使用已安装依赖的 32 位 Python，并配置本机授权模板目录：

```powershell
$env:PYTHONPATH = (Resolve-Path .\mcp_server).Path
$env:MULTISIM_MCP_TEMPLATE_DIR = '本机授权模板包的绝对路径'
python -m multisim_mcp.native_analog_acceptance --output .\sample_multisim\analog-new-run
```

需要本机可用的 Multisim COM、`ewd/ewe` 编解码工具；已有输出目录会被拒绝。
运行入口是 `mcp_server/multisim_mcp/native_analog_acceptance.py`。它不连接外部 AI 服务，
用于先验收底层生成和原生执行能力，后续自然语言规划器应调用同样的执行和验收机制。

产物包括：

- `report.html`：候选比较、选中工程下载、Multisim 电路图和实验链接。
- `acceptance.json`：逐项电气判定、容差、测量指标、失败原因。
- `rc-1600/analysis-003.ms14`：本例选中方案在实际仿真时保存的工程快照。
- 各实验的 `analysis-*/data.csv` 和 `native-result.json`：完整轴和数据。
- 各实验的 `run.json`：本机版本、动作、参数读回、恢复和源文件校验信息。
- `manifest.json`：所有证据文件的 SHA-256。本次复核 132 项，无哈希不符。

失败时入口返回非零退出码并保留证据，不调用命令引擎补成成功结果。
底层通用 `run_native_project` 的 `completed` 仅表示执行完成，仍然保留 `unverified`；
本基准的 `acceptance.json.passed` 才表示这里明确列出的检查全部通过。

## 修复和边界

1. 计算引脚位置时应用模板内部旋转和平移，并将符号和引脚一起定位。
2. 为精确匹配的电源—串联电阻—并联 R/C 拓扑提供不穿越元件的专用布线。
3. 简单 SPICE 电阻使用参数可编辑的理想模型；不继承可能被 XML 属性折行破坏的温度模型表达式。
4. 校正本机 `DC_POWER` 模板的电压源端子极性，同步显式 DC/AC 数值与可编辑属性，避免仍显示模板的 15 V。
5. 为多探针分配独立输出名称、数据包和触发器标识，返回探针与网络的输出映射。
6. 修正小数/科学计数法的原生数值序列化，避免生成 `0.1.` 或 `1e-07.`。
7. 原生瞬态全部通道在同一次仿真中采集；导出完整数据并检查轴、时长和截断。

本次结果只覆盖 Multisim 14.3 和本机模板包。更换版本或元件模板需要重新运行基准，
不能由版本字符串或模板名称推断引脚、极性、模型和探针一定兼容。
电源的脉冲部分保存在 SPICE 表达式中，电路图数值显示 DC 属性；报告给出完整激励条件。
任意拓扑布线、容差/负载/温度分析、导入电路修复、多板协同、PCB 制造规则以及独立软件的 AI 交互仍需继续实现和验收。

最终回归：680 项测试，672 通过、8 跳过；本次运行包含本机授权模板测试。
