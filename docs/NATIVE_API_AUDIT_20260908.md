# Multisim 原生自动化接口审计（2026-09-08）

使用 Multisim 14.3 的 32 位 COM 进程读取 `IMultisimApp` 和
`IMultisimCircuit` 类型库。审计命令：

```powershell
& '<python32>' `
  tools/probe_multisim_native_api.py --blank
```

当前接口明确提供：打开/新建工程、元件名称枚举、替换元件、仿真运行、输入输出配置、网表/BOM/图片/报告导出和保存。

当前接口未发现：放置元件、创建元件、创建导线、连接引脚、读取元件几何引脚的公开方法。`EnumComponents` 返回的是元件名称字符串，而不是可操作的元件对象。

因此，原生 COM 目前适合作为**验证、仿真、导出和有限替换后端**，不能据此宣称可以完全替代 XML/模板生成器完成从空白工程自动布线。后续生成仍必须由经过版本验证的模板/编码器完成，再由原生 Multisim 打开、运行、导出网表并做拓扑复核；若后续发现命令文件或未公开接口能创建元件/导线，必须先加入最小 R-C 闭环回归，才能扩大使用范围。
