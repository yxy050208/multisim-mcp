# v1.3.0-preview.2

这是第二阶段原生电路验收预览版。它在 MCP 工作流中加入了可重复的 2N3904 共射放大器案例，并把“自然语言需求 → 原生 Multisim 图纸 → 仿真 → 指标验收 → 报告/图片导出”串成可审阅闭环。

## 本版已验证

- `run_natural_common_emitter`：中文需求生成单管共射放大器；
- 真实 Multisim 14.3 原生直流源、脉冲源、2N3904、偏置网络、耦合电容和负载；
- 工作点、1 kHz 增益、相位、脉冲响应、拓扑和模型指纹验收；
- 原生 `.ms14`、网表、CSV、波形图、报告和 manifest 导出；
- 图纸布局按信号流向组织，测量面板默认隐藏，元件值采用工程记数法；
- 完整回归：784 tests passed，8 skipped；
- DSH 插件发布元数据检查通过（插件版本 1.1.0，核心版本 1.2.0）。

## 已知边界

- 当前真实元件验收集中在 Multisim 14.3 的 LM324AJ 和 2N3904；
- 新生成工程仍要求用户进行一次图面复核，交付状态会明确标记 `requires-visual-review`；
- 尚未声称任意复杂电路、开关电源、容差/温漂/噪声或多板自动生成已经完成；
- 64 位 Python 负责 MCP/Agent 层，Multisim COM 仍通过独立 32 位 worker；
- 本版不包含独立桌面前端。

## GitHub 发布建议

可以作为开发分支预览版更新 GitHub。发布前应在目标机器重建本地组件包，并用已授权的 Multisim 运行一次 `runtime_status` 和共射极示例；不要提交本地 `.ms14`、解码 XML、类型库转储或实验输出。
